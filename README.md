Ant Worker Counter & Estimator (アリのワーカー数 自動計測＆推計ツール)

1枚の写真や複数アングルから撮影した写真から、アリのワーカー数を自動で検出し、コロニー全体のトータル数を統計的に推計・集計するWebアプリケーションです。スマホやPCのブラウザからインストール不要で利用できます。

【特徴】

・1枚〜複数枚の画像に対応: 単一の写真での直接カウントはもちろん、複数アングルの画像一括アップロードに対応。

・統計的推計: 複数画像のデータから「最大アングル値 (Max)」「平均値 (Average)」「死角・重複補正推計」を自動計算し、コロニーの全貌を把握しやすくします。

・感度調整機能: サイドバーのスライダーで、ゴミの除去や検出サイズをリアルタイムに微調整可能。

【使い方】

公開されたWebアプリのURLにアクセスします。

アリの巣やケースを撮影した写真をアップロードします（複数選択可）。

画面に表示される検出枠、および「最大値・平均値・補正推計値」を確認します。

【使用技術】
・Python
・Streamlit
・OpenCV (opencv-python-headless)
・NumPy
